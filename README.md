# PyBrowser — свой браузер на Python с ИИ-генератором плагинов

## Как запустить в PyCharm (по шагам)

1. **File -> Open** -> выбери папку проекта.
2. В правом нижнем углу (или Run -> Edit Configurations) проверь, что интерпретатор — Python 3.10+.
   Если не выбран: шестерёнка -> Add Interpreter -> Add Local Interpreter -> System/venv.
3. Открой терминал внизу PyCharm (вкладка Terminal) и выполни:
   ```
   pip install -r requirements.txt
   ```
4. Открой файл `main.py`, нажми **правой кнопкой -> Run 'main'**.
   (или зелёный треугольник ▶ слева от пустой строки в начале файла)

## Что внутри

```
main.py                 <- запускать этот файл
config.py               <- настройки (стартовая страница, выбор ИИ)
requirements.txt        <- список библиотек
core/                   <- ядро браузера
    tabs.py             <- вкладки
    storage.py          <- история + закладки (SQLite в data/browser.db)
    plugin_manager.py   <- загружает плагины из папки plugins/
    sandbox_check.py    <- проверка безопасности кода плагинов
ai/                     <- ИИ-ассистент
    client.py           <- связь с Ollama / DeepSeek
    prompt.py           <- шпаргалка для модели (API плагинов)
    generator.py        <- конвейер: запрос -> код -> проверка -> файл
ui/
    window.py           <- главное окно (тулбар, вкладки, панель ИИ)
plugins/
    dark_theme.py       <- пример плагина (тёмный режим страниц)
data/                   <- база истории/закладок (создаётся сама)
```

## Как подключить ИИ (для генерации плагинов)

Вариант А — бесплатно, локально (рекомендую):
1. Установи https://ollama.com
2. В терминале: `ollama pull qwen2.5-coder:3b`
3. В `config.py` оставь `USE_OLLAMA = True`.

Вариант Б — облако (DeepSeek/OpenAI):
1. Получи API-ключ.
2. В `config.py`: `USE_OLLAMA = False`, `USE_CLOUD = True`, впиши `CLOUD_API_KEY`.

## Пользоваться ИИ-генератором

Внизу окна браузера есть поле. Напиши, например:
- «скрывай все изображения»
- «показывай количество слов страницы»
- «подсвечивай ссылки синим»

Нажми «Создать плагин 🤖». Модель напишет код, браузер проверит его
на безопасность и положит в `plugins/`. Кнопка «Плагины ⟳» перечитывает папку.

## Возможные проблемы

- **«Running as root without --no-sandbox»** (Linux под root): запусти так:
  `QTWEBENGINE_CHROMIUM_FLAGS="--no-sandbox" python main.py`
  На Windows/macOS этого не бывает.
- **Ошибка связи с ИИ**: не запущен Ollama (`ollama serve`) или нет интернета.
- **Плагин не применился сразу**: JS внедряется при следующей загрузке страницы — нажми ⟳.
